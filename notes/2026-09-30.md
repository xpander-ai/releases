> [!IMPORTANT]
> **Action required.** Run every step below, in order. This release moves agent executors to **unprivileged** containers automatically during the upgrade.

**Helm chart:** `xpander-airgap` `0.14.32` · **Platform build:** [`8e4f65582a26919e1a809e1f8e8366d94fbe0524`](https://github.com/xpander-ai/releases/releases/tag/release-8e4f65582a26)

## What's new

- Workflows are generally available in the new interface.
- Duplicating an agent copies its computer files.
- Old-generation agents migrate to the new architecture with their files.
- Agent schedules are in agent **Settings**.
- More reliable MCP token refresh, long sessions and responses.

## Security

- Agent executors run unprivileged: no privileged containers, `hostUsers: false`, zero capabilities, egress through a filtering proxy.
- The fleet API key no longer reaches the agent sandbox.
- Tighter executor network policy; fleet jobs run with seccomp and dropped capabilities.

## Upgrade

Replace `<namespace>`, `<your-registry>` and `<xpander-token>` (from your license email). Every command works from a terminal or a CI/CD pipeline.

**1. Check the nodes.** Every node must show kubelet `v1.33` or later, kernel `6.3` or later, and containerd `2.0` or later. Upgrade any node that doesn't before you continue.

```bash
kubectl get nodes -o custom-columns=NODE:.metadata.name,KUBELET:.status.nodeInfo.kubeletVersion,KERNEL:.status.nodeInfo.kernelVersion,RUNTIME:.status.nodeInfo.containerRuntimeVersion
```

**2. Download the release.**

```bash
curl -fsSL https://charts.xpander.ai/image_sync.sh -o image_sync.sh
curl -fsSL https://github.com/xpander-ai/releases/releases/download/onprem-36741800359/approved-release-manifest.json -o release-manifest.json
```

**3. Mirror the images.** This writes `pins.yaml`, which pins every image to this release.

```bash
bash image_sync.sh --source-user xpanderaihub --source-token <xpander-token> \
  --dest <your-registry> --release-manifest release-manifest.json --manifest-out pins.yaml
```

**4. Upgrade.** The upgrade moves existing agent files to their new owner, then starts the unprivileged executors.

```bash
helm registry login registry-1.docker.io -u xpanderaihub -p <xpander-token>
helm upgrade xpander oci://registry-1.docker.io/xpanderaihub/xpander-airgap --version 0.14.32 \
  -n <namespace> --reuse-values -f pins.yaml --wait --timeout 30m
```

**5. Verify.** The command must print nothing.

```bash
kubectl -n <namespace> get pods -o jsonpath='{range .items[*]}{.metadata.name}{" "}{.spec.containers[*].securityContext.privileged}{"\n"}{end}' | grep true
```

Then run the [verification guide](https://pages.xpander.ai/airgap-verification-guide).
